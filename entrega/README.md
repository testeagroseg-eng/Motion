# AgrosegPlay — motion de divulgação

Vídeo vertical 1080 × 1920, 30 fps, 40,2 segundos, com as seis falas enviadas, na ordem de 01 a 06, e encerramento com play.agroseg.net.br.

## Assistir ou baixar

Abra `AgrosegPlay.mp4` no GitHub e use **Download raw file**. Para assistir com o player local, baixe esta pasta inteira e abra `index.html` no navegador.

`previa.jpg` apresenta oito quadros reais do vídeo.

As imagens de apoio, a interface exibida e o lettering são propostas ilustrativas, sem uso de logotipo oficial.
